# Tunnel Gauge

A lightweight Laravel performance console for measuring a Dev Tunnel from the browser. The dashboard reports Laravel response timing, browser round-trip time, HTML transfer size, request metadata, and runtime versions. It includes a bounded CPU benchmark and a parallel burst test against a no-cache health endpoint.

## Requirements

- PHP 8.3 or newer
- Composer 2

The application does not require a database or frontend build step. No third-party scripts, fonts, or runtime services are loaded.

## Run on Windows

Install PHP and Composer, then open a new PowerShell terminal so PATH changes take effect. From this project directory:

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
php artisan serve --host=0.0.0.0 --port=3000
```

Open `http://localhost:3000`. Keep the existing Dev Tunnel forwarding local port `3000`; the dashboard will report the forwarded host and HTTPS protocol. Laravel trusts forwarded proxy headers so diagnostics show the external request details.

## Endpoints

- `/` - performance console
- `/health` - uncached JSON health and request diagnostics
- `/benchmark?iterations=100000` - bounded SHA-256 workload (1,000 to 500,000 iterations)

## Tests

```powershell
php artisan test
```

The tests cover the dashboard timing headers and both diagnostic endpoints.
